🚀 QUICK START GUIDE
================================================================================

LANGKAH 1: PERSIAPAN (DI LOKAL - 15 MENIT)
─────────────────────────────────────────
[ ] Backup database lokal:
    mysqldump -u root -p database_name > backup_gajipro.sql

[ ] Build assets:
    npm install
    npm run build

[ ] Generate APP_KEY:
    php artisan key:generate
    (catat nilai APP_KEY)

[ ] Siapkan credentials:
    - cPanel username & password
    - Domain name
    - FTP credentials (jika pakai FTP)

LANGKAH 2: UPLOAD KE HOSTINGER (30-60 MENIT)
─────────────────────────────────────────────
[ ] Login ke cPanel Hostinger

[ ] Buat database baru:
    - cPanel → MySQL Databases
    - Catat: Database Name, Username, Password

[ ] Upload files:
    - File Manager atau FTP
    - Upload ke public_html/ (exclude node_modules & vendor)
    - Tunggu upload selesai

LANGKAH 3: KONFIGURASI (15-30 MENIT)
─────────────────────────────────────
[ ] Buat file .env di public_html/:
    - Isi dengan database credentials
    - Isi dengan APP_KEY
    - Isi dengan domain URL

[ ] Set folder permissions:
    - storage/ → 755
    - bootstrap/cache/ → 755

[ ] Point domain ke public/:
    - cPanel → Domains
    - Document Root: public_html/public
    - (Atau buat .htaccess jika tidak bisa)

[ ] Restore database:
    - phpMyAdmin
    - Import backup_gajipro.sql
    - Tunggu selesai

LANGKAH 4: VERIFIKASI (10 MENIT)
────────────────────────────────
[ ] Akses domain di browser
[ ] Halaman muncul? (bukan blank/error)
[ ] Coba login
[ ] Cek error logs (jika ada)

TOTAL WAKTU: 70-135 MENIT

================================================================================
📋 TIPS & BEST PRACTICES
================================================================================

✅ DO:
  • Backup database sebelum migrasi
  • Jalankan npm build lokal sebelum upload
  • Test di lokal dulu sebelum production
  • Cek error logs jika ada masalah
  • Print checklist & track progress
  • Catat semua credentials di tempat aman
  • Communicate dengan client/team

❌ DON'T:
  • Upload node_modules/ (terlalu besar)
  • Upload vendor/ (kecuali perlu)
  • Upload .env lokal (buat baru di Hostinger)
  • Jalankan destructive commands di production
  • Lupa backup database
  • Lupa generate APP_KEY
  • Upload & run tanpa testing

⚠️ IMPORTANT:
  • Hostinger tidak punya SSH → semua compile di lokal
  • .env JANGAN di-commit ke git
  • APP_KEY HARUS di-generate
  • public/ folder HARUS menjadi web root
  • storage/ & bootstrap/cache/ HARUS writable

================================================================================
🔍 TROUBLESHOOTING QUICK REFERENCE
================================================================================

ERROR 500?
→ Check APP_KEY & database credentials di .env
→ Check storage/logs/laravel.log

Database connection error?
→ Verify database credentials di .env
→ Check database exist di phpMyAdmin

Assets (CSS/JS) tidak muncul?
→ Check public/build/ folder ada
→ npm run build belum dijalankan?

404 Not Found untuk semua route?
→ Document Root belum pointing ke public/

Permission denied pada storage/?
→ Set folder permission ke 755

Untuk lebih detail → Lihat PANDUAN_MIGRASI_HOSTINGER.md (Troubleshooting section)
