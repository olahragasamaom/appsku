FASE 5: TROUBLESHOOTING (JIKA ADA ERROR)
================================================================================

ERROR: 500 Internal Server Error
  [ ] Ubah APP_DEBUG=true di .env sementara
  [ ] Reload halaman, lihat error detail
  [ ] Cek file storage/logs/laravel.log
  [ ] Cek cPanel Error Log
  [ ] Kemungkinan: APP_KEY kosong, database config salah, permission issue
  Solusi:
    [ ] Verifikasi APP_KEY di .env
    [ ] Verifikasi DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD
    [ ] Verifikasi folder permissions

ERROR: SQLSTATE[HY000]: General error / Can't connect to database
  [ ] Verifikasi database exist di cPanel phpMyAdmin
  [ ] Verifikasi database username & password
  [ ] Cek .env: DB_HOST biasanya 'localhost'
  [ ] Verifikasi database user punya akses ke database
  Solusi:
    [ ] Buka phpMyAdmin, test login dengan credentials di .env
    [ ] Jika gagal, recreate database user di cPanel

ERROR: Assets CSS/JS tidak dimuat (halaman tidak punya style)
  [ ] Verifikasi folder public/build/ ada (via File Manager)
  [ ] Verifikasi file public/build/manifest.json ada
  [ ] Cek DevTools → Network (public/build/* status berapa?)
  Solusi:
    [ ] Jalankan ulang npm run build di lokal
    [ ] Re-upload folder public/ ke Hostinger
    [ ] Clear browser cache (Ctrl+Shift+Del)
    [ ] Coba akses dengan Incognito mode

ERROR: 404 Not Found untuk semua route
  [ ] Verifikasi domain pointing ke public_html/public
  [ ] Jika pakai .htaccess, verifikasi rewrite rules benar
  [ ] cPanel → Error Log (ada error Apache/mod_rewrite?)
  Solusi:
    [ ] cPanel → Domain settings, ubah document root ke public_html/public
    [ ] Atau update .htaccess rewrite rules

ERROR: Blank page (tanpa pesan error)
  [ ] Ubah APP_DEBUG=true di .env
  [ ] Reload halaman
  [ ] Cek error detail di browser
  [ ] Cek storage/logs/laravel.log
  Solusi:
    [ ] Lihat error message detail setelah enable APP_DEBUG

ERROR: Permission denied pada storage/ atau bootstrap/cache/
  [ ] File Manager → folder storage → Properties
  [ ] Set permission ke 755
  [ ] Folder bootstrap/cache → Set permission ke 755
  Solusi:
    [ ] Ubah folder permission via File Manager cPanel
